1.核心参数

| `-m`   | `哈希类型代码`    | `-m 1000=NTLM`<br>`-m 0=MD5`<br>`-m 100=SHA-1` |
| ------ | ----------- | ---------------------------------------------- |
| -a     | 攻击模式        | -a 0=字典攻击<br>-a 3=暴力破解(掩码)                     |
| -O     | 优化内核(提速10倍) | 限制密码长度<=31位，实战默认加上                             |
| --show | 显示已爆破的结果    | hashcat -m 0 hash.txt --show                   |
2.实战命令模板
	`hash -a [攻击模式] -m [哈希类型] -O hash.txt [字典路径]`
	`#带规则`
	`hashcat -a 0 -m 0 -O hash.txt [字典.txt] -r rules/bast66.rule`
	`hashcat -a 0 -m 0 -O hash.txt [字典.txt] -r rules/d3ad0ne.rule`
	`#掩码攻击(固定前缀+数字后缀)`
	`hashcat -a 3 -m 0 -O hash.txt 前缀?d?d?d`
	例如:hello123->hashcat -a 3 -m 0 hash.txt hello?d?d?d 
	`#查看破解结果`
	`hashcat -m [类型] hash.txt --show`
3.具体
	`hashcat -a 0 -m 0 hash.txt example.dict`
	`hashcat -a 0 -m 0 hash.txt "常见于默认密码/SecLists-master/Passwords/Common-Credentials/Language-Specific/Chinese-common-password-list-top-1000000.txt"`
	`(其中里面的Chinese-common-password-list-top-1000000.txt也可以用Chinese-common-password-list.txt)`
	`hashcat -a 0 -m 0 hash.txt "常见于默认密码/SecLists-master/Passwords/Common-Credentials/10k-most-common.txt(这个可以换成Pwdb_top-100000.txt或者更大的字典xato-net-10-million-passwords-1000000.txt)"`
