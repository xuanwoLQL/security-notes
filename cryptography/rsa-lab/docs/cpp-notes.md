# RSA 实验 C++ 精简版说明

## 编译

```bat
g++ -O2 -static rsa.cpp -o rsa_cpp.exe
```

也可以直接双击 `build.bat`。只使用 C++ 标准库，不需要 GMP、OpenSSL、Boost。

## 使用方式

程序只保留交互菜单，不再接受任何命令行开关：

```text
=================== RSA 加解密工具 ===================
 1. 生成密钥对（默认 512 位，分别写入 public.txt / private.txt）
 2. 加密（默认使用 public.txt 中的公钥）
 3. 解密（私钥来源需手动选择）
 4. 查看密钥文件
 5. 核心运算自检
 0. 退出
======================================================
```

主菜单的 `5` 是自检；为兼容旧习惯，输入 `9` 也会执行同一个 `selfTest()`。

## 密钥文件

- `public.txt`：只包含 `n` 和 `e`，供加密使用。
- `private.txt`：包含 `n`、`d` 以及 CRT 参数 `p`、`q`、`dp`、`dq`、`qinv`，首行是明文私钥警告。
- `key.txt`：旧版文件，同时包含 `n`、`e`、`d`，仅用于向后兼容。

密钥文件沿用 `name = value` 格式，支持 `#` 注释、空行和大小写不敏感的键名。

## 解密流程

选择菜单 `3` 后，必须手动选择私钥来源：

- `a`：从 `private.txt` 读取。若没有 `private.txt`，会回退检查旧版 `key.txt`；读取前必须输入 `y/Y` 确认。
- `b`：手动输入 `d`。Windows 下用 `_getch()` 逐字符读取并显示 `*`；POSIX 下关闭终端回显。
- `c`：返回主菜单。

从 `private.txt` 解密时使用 CRT 加速；手动输入 `d` 或旧版 `key.txt` 没有 CRT 参数时，回退到普通模幂解密。加密路径只读取 `n`、`e`，不会解析任何私钥字段。

## 安全须知

本程序仅用于教学演示：

- `private.txt` 中的私钥是明文，真实环境必须加密存储或使用硬件保护；
- `private.txt` 中的 CRT 参数同样属于私钥材料，安全级别等同 `d`；
- 进程内存中的 `d` 也是明文，教学版没有实现安全擦除；
- 真实实现应使用 PKCS#1 + OAEP 填充，并使用 CRT 加速解密；
- 程序已移除 CLI 参数入口，避免私钥出现在 shell history、`ps` 或进程命令行中；请勿重新加入 `-d <n> <d> <hex>` 之类入口。

## 与旧版兼容

- 分组方式不变：每块明文 `n 的字节数 - 1` 字节，每块密文固定 `n 的字节数`；
- 旧版 `rsa.exe` 用 `key.txt` 生成的密文，新版在确认后可以解密；
- 生成新密钥时只写 `public.txt` 和 `private.txt`，不会删除已有的 `key.txt`。

## 关于“直接调库”

如果只是做应用，OpenSSL 的 `BN_mod_exp`、`RSA_generate_key_ex` 可以把代码压到一百多行；但实验要求自己实现大数运算、素性检测和密钥生成，所以这里仍使用 C++ 标准库手写大整数。真实系统不应把这段教学代码直接用于生产。
