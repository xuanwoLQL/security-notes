# Python 网络编程学习代码

本目录保留 Socket 编程、并发模型和文件传输练习的源码与笔记，适合按主题逐步阅读和改造。

## 学习路线

| 目录 | 主题 |
| --- | --- |
| `fork理解和使用/` | 进程、`fork` 与聊天室基础 |
| `socketserver编程实验/` | TCP、UDP、多线程与聊天服务 |
| `GUI聊天室实例作业/` | Tkinter 图形界面聊天室 |
| `multiprocessing作业/` | 多进程文件复制 |
| `多进程文件下载作业/` | 多进程文件下载 |
| `实验五-基于多线程的文件下载实验/` | 多线程下载与并发测试 |
| `作业-消息&文件上传和下载/` | 自定义协议与文件上传 |
| `基于Socket编程的FTP服务器/` | 简易 FTP 服务 |
| `基于非阻塞IO模型(select)的并发实验/` | `select` 非阻塞 I/O |
| `模块大作业-文件上传下载服务/` | TCP 网盘系统 |
| `考前复习/` | TCP/UDP 复习示例 |

根目录还包含 UDP/TCP 示例、自定义协议、URL 请求与端口扫描等单文件练习。

## 推荐阅读方式

1. 先运行简单的 UDP/TCP 客户端和服务端，观察通信过程。
2. 再阅读自定义协议和文件传输代码，重点理解消息边界、分块传输与完整性校验。
3. 最后阅读多线程、多进程和 `select` 版本，比较三种并发模型的取舍。

每个实验目录中的 `需求文档.txt` 可用于了解练习目标；运行代码前请先阅读源码，避免直接运行来源不明的程序。
