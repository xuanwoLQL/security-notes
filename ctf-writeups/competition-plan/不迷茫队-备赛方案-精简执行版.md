## 八、一页速查（开工前 1 分钟看一遍）

**渗透开局 5 步**

1. `nmap -sV -T4 -p- 目标`（先全端口，别只扫常见端口）
2. 目录扫描 + 备份文件：`.zip .bak .git .svn .DS_Store`
3. 指纹识别（EHole / WhatWeb）→ 确定框架版本 → 找对应 CVE
4. 看 robots.txt、sitemap、JS 里的接口和密钥
5. 弱口令尝试：后台、数据库、SSH、RDP

常见 flag 位置：Web 根目录及上级、`/root/flag`、`/home/*/flag`、`C:\Users\Administrator\Desktop\flag*`、数据库表、后台页面。

**应急排查"九看"**：看账号、看登录、看进程、看端口、看任务、看启动、看文件时间、看日志、看流量。

Windows 重点关注事件 ID：**4624** 登录成功、**4625** 登录失败（爆破）、**4688** 进程创建、**4720/4726** 建/删用户、**4697/7045** 服务安装、**4698** 计划任务、**1102** 日志被清除。

Linux 先看这几处：`awk -F: '$3==0' /etc/passwd`、`cat /etc/ld.so.preload`、`crontab -l`、`last`/`lastb`、`/var/log/auth.log`、`find / -perm -4000 -type f`、近期被改的 `.php/.jsp`。

**答案格式 3 条**

1. IP、路径、文件名一律复制粘贴，不手打。
2. 时间注意时区（+8）与格式，拿不准就带上秒。
3. 每题先记"答案 + 证据（命令或日志原行）"，提交前交叉复核。

**纪律三条**：不跨组交流、不碰平台、所有提交走 D。
