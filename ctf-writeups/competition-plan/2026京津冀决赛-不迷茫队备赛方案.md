### 2. 渗透测试实战场景赛（150 分钟）

通知原文要点：依托典型企业网络架构、业务应用系统环境搭建独立靶场，内置各类企业真实网络服务与 Web 业务场景；选手使用环境提供的渗透测试工具，通过信息收集、漏洞挖掘与漏洞利用，对整体网络环境进行安全研判；得分考点分布在**网络拓扑、系统配置、Web 页面、本地文件**等不同位置；根据题目获取 flag 并提交平台计分，设置多梯度难度考题，不同考题对应不同分值。

四条解读：

1. 这不是单点 Web 题，而是**一整张企业网**：外网打点 → 提权 → 内网横向的链式场景，后半程分值往往更大。
2. 考点分布在网络拓扑、系统配置、Web 页面、本地文件四类位置，说明除 Web 漏洞外，弱口令、服务配置缺陷、信息泄露同样是考点。
3. 多梯度难度意味着**必有送分题**（默认口令、目录泄露、备份文件、简单注入），开局必须先摘低垂果实，保证基础分。
4. flag 提交计分 → 必须设专人统一提交并登记，避免重复提交、格式错误与漏交。

### 3. 应急响应实战场景赛（190 分钟）

通知原文要点：场景结合网络安全应急响应实践知识点，提供**被入侵的服务器**，在内置靶机中安装网站、数据库、OA 等类型业务系统；选手对服务器进行分析，寻找被植入的恶意程序及其他恶意行为痕迹；**可参考基础提示信息**，根据题目问题针对靶机进行漏洞寻找、分析，然后提交答案自动化评分；题目按难度设不同分值。

四条解读：

1. 典型形态是"给一台已被入侵的机器 + 一张问题清单"：攻击者 IP、首次入侵时间、Webshell 路径与密码、恶意进程、持久化方式、被窃数据、横向目标等。
2. 题目自带**基础提示信息**，务必先把提示读全抄进台账——很多题是顺着提示的线索走，而不是盲搜。
3. 答案格式极其关键（IP / 路径 / 时间 / 文件名 / 哈希），错一个字符即不得分：一律复制粘贴，不手打；时间注意日志时区与格式要求。
4. 3 小时 10 分比渗透赛还长，说明题目量大、层次多：先把问题清单按"能秒答 / 要找 / 要挖"分类，再分配时间。

- 严禁跨组交流及分享任何解题思路；比赛期间仅限组内交流。

- 全程录屏监控；赛后有权抽查各选手系统日志与答题思路，异常操作将扣分乃至取消资格。

## 三、目标与分工

### 1. 目标

- 保底目标：两个赛道均有有效得分（不空手），总分进入 88 支决赛队伍的中上区间。
- 冲击目标：渗透赛道完成"外网打点 → 提权 → 内网横向"完整链路；应急赛道拿下全部基础与中等难度题并尝试高难度题，争取获奖。
- 过程目标：19 天内完成 60+ 道专项题、8 套内网靶场全流程、2 次全真模拟赛、1 份队内速查卡（附录 B/C）。

### 2. 角色分工

| 代号 | 角色 | 主要职责 | 赛道定位 |
| --- | --- | --- | --- |
| A | 队长 / 渗透主攻 | Web 漏洞利用、payload 构造、外网打点、节奏决策 | 渗透主攻 |
| B | 内网与后渗透 | 信息收集、提权、代理隧道、横向移动、域内渗透 | 渗透副攻 |
| C | 应急响应主攻 | 日志分析、Webshell 查杀、持久化排查、内存与流量取证 | 应急主攻 |
| D | 协同与 AI 操作员 | 题目台账、flag 提交、脚本自动化、AI 调用、计时与同步提醒 | 两赛道辅助 |

赛段切换：

- 渗透段（9:30—12:00）：A 主攻 Web 打点，B 负责端口扫描与内网推进，C 辅助信息收集（目录、指纹、备份文件），D 维护台账、统一提交 flag、每 15 分钟报时。
- 应急段（12:20—15:30）：C 指挥并主攻日志与取证，A 负责 Windows 侧排查，B 负责 Linux 侧排查，D 负责问题清单、答案整理与提交。

### 3. 协作规则

1. 每 15 分钟一次 30 秒同步，只报"新发现 / 卡点 / 需要支援"三件事。
2. flag 与答案由 D 统一提交并登记（来源、分值、提交时间），任何人不单独提交。
3. 单人卡住超过 15 分钟必须换人或求助，场景赛最怕死磕。
4. 关键结论实时写进共享台账，既是团队记忆，也是赛后抽查时的自证材料。

## 五、训练内容矩阵 B：应急响应赛道

### 1. 标准处置流程（背下来）

准备 → 确认（现象、时间、影响面） → 抑制（隔离，但先保留现场） → 取证（内存、日志、磁盘、流量，**先取证后处置**） → 根除（清恶意程序、堵漏洞、改口令） → 恢复 → 复盘。

### 2. 知识点与训练平台

| 模块 | 考点 | 平台 / 工具 | 目标 |
| --- | --- | --- | --- |
| Windows 应急 | 进程、端口、服务、计划任务、启动项、注册表（Run/Winlogon）、事件日志、影子账号、入侵痕迹 | 玄机应急靶场、墨者、合天；Sysinternals（Autoruns/ProcExp/ProcMon）、FullEventLogView、PCHunter、D 盾、LogParser | 5 个场景 |
| Linux 应急 | 账号（UID=0、authorized_keys、sudoers）、登录日志、计划任务、启动项、ld.so.preload、内核模块 rootkit、SUID、反弹 Shell、挖矿、Web 日志审计 | 玄机、墨者；Kali（chkrootkit/rkhunter/osquery） | 5 个场景 |
| Web 应急 | Webshell 查找（时间线、文件特征、日志 POST 记录）、中间件日志（access/error、Tomcat、Weblogic）、框架攻击日志特征（Shiro/Fastjson/Log4j/ThinkPHP）、数据库日志 | 玄机、墨者；D 盾、河马 | 4 个场景 |
| 流量分析 | 过滤语法、HTTP 对象导出、追踪流、爆破/Webshell/C2 特征、DNS 隧道、CS Beacon 心跳 | Wireshark、tshark、公开 pcap 赛题 | 5 个 pcap |
| 内存取证 | Volatility 3（pslist/pstree/cmdline/netscan/malfind/hashdump/filescan）、进程注入识别 | Volatility 3 + 公开内存镜像 | 2 个镜像 |
| 数字取证与杂项 | 文件时间线、文件雕刻、哈希校验、编码解码、勒索与挖矿样本分析 | Kali（binwalk/foremost）、CyberChef、VirusTotal、微步与奇安信沙箱 | 按需 |

### 3. 答案规范化（自动评分的关键）

- IP：先判断是内网还是公网地址，警惕 NAT 与日志中的内网来源。
- 时间：注意时区（+8）与格式要求，含秒更稳妥。
- 路径：Windows 反斜杠与盘符、Linux 绝对路径，严格照题目提示格式。
- 文件名与哈希：MD5 一律小写且无空格。
- 每题先在草稿记"答案 + 证据（命令或日志原文）"，提交前交叉复核。

## 七、AI 协作机制

### 1. 赛前：把 AI 变成随队助教

- 建知识库：把现有 CTF 笔记与队伍 write-up 整理成"考点 → 套路 → 命令/payload"三级结构，作为本地检索库与复习材料。
- AI 出题自测：针对某个考点让 AI 生成 10 道变体题，做完请它批改，比看文章效率高。
- AI 讲原理：卡住时要求它解释"为什么这样构造"，赛后必须能用自己话复述，否则等于没学会。
- AI 造数据：生成日志片段、可疑 pcap 特征、伪装过的恶意脚本，用于练习排查与识别。
- 沉淀速查卡：把每次复盘结论压缩成附录 B/C 的形式，赛前打印。

### 2. 赛中：定位与边界

定位：AI 是加速器，不是决策者。AI 给出的 payload、命令、结论，必须在本地环境验证原理后再用于靶机。

合规边界（重要）：通知明确"严禁跨组交流及分享任何解题思路"，并有权抽查答题思路、全程录屏。因此建议：

- 赛前向指导老师与组委会确认 AI 工具的使用口径；
- 采纳保守做法：赛中优先使用**本地离线模型**（如 Ollama 加载 qwen2.5-coder / deepseek-r1）与本地工具（CyberChef、ToolsFx、离线知识库、速查卡）；
- 公共在线 AI 仅用于通用知识查询（如"某漏洞原理""某命令参数"），不上传 flag、靶机 IP、题目原文与目标截图，避免被认定为借助外部协助；
- 全程保留操作记录与思路笔记，即便被抽查也能自证。

可用场景清单：

| 场景 | 说明 |
| --- | --- |
| 代码审计 | 用 AI 快速定位危险函数、串联 POP 链、找出可利用参数 |
| payload 构造与变形 | 被 WAF 拦截后生成等价变形，节省试错时间 |
| 日志与流量解析 | 把日志片段/tshark 输出交给 AI 归纳可疑点（注意脱敏） |
| 编码与解密 | 自定义加密、混淆脚本还原 |
| 快速写脚本 | 批量请求、结果提取、数据清洗 |
| 报错与命令补全 | 省去查文档时间 |

### 3. 赛后：复盘与沉淀

- 用 AI 把当天记录整理成 write-up 初稿，人工补齐"为什么这么做"。
- 每题压缩成"考点 → 套路 → 命令"三行，进知识库。
- 每周用 AI 出一套自测卷，检验记忆与手感。


| SSRF | 内网探测、gopher/file/dict 协议利用、打 Redis 与内网服务 |
| Fastjson / Log4j | JNDI 注入（LDAP/RMI + 恶意类加载） |
| Redis 未授权 | 写 SSH 公钥、写计划任务、主从复制 RCE |
| 中间件 | Tomcat 后台与 CVE-2017-12615、Weblogic、JBoss |
| 提权 | Linux（sudo -l、SUID、内核、计划任务）；Windows（服务权限、令牌、烂土豆系列） |
| 内网横向 | 代理（frp / Neo-reGeorg / suo5 / Proxifier）→ fscan 探测 → 凭据抓取 → psexec/wmiexec/nxc |
| 域渗透 | BloodHound + SharpHound 信息收集、Kerberoast / AS-REP、票据、DCSync |

### 2. 常见 flag 位置

- Linux：Web 根目录与上级目录、/root/flag*、/home/*/flag*、数据库表、环境变量、计划任务文件。
- Windows：C:\Users\Administrator\Desktop\flag*、网站根目录、服务配置、注册表、数据库。
- 其他：后台页面、图片元数据、注释与源码、备份文件。

### 3. 开局信息搜集顺序

1. nmap -sV -T4 -p- 目标（先全端口，不要只扫常见端口）
2. 目录与文件扫描（dirsearch）+ 备份与版本文件（.zip/.bak/.git/.svn/.DS_Store）
3. 指纹识别（EHole / TideFinger / WhatWeb）→ 确认框架与版本 → 匹配已知 CVE
4. 检查 robots.txt、sitemap、JS 文件中的接口与硬编码密钥
5. 弱口令尝试（后台、数据库、SSH、RDP）

## 附录 D：一键信息采集脚本（仅用于比赛靶机与自有授权环境）

### 1. Linux

```bash
#!/bin/bash
# 用途：应急响应场景快速采集基础信息（仅在授权环境使用）
OUT=/tmp/ir_$(date +%Y%m%d_%H%M%S); mkdir -p "$OUT"
{
  echo "===== 时间 ====="; date; uptime
  echo "===== 账号 ====="; cat /etc/passwd; awk -F: '$3==0{print}' /etc/passwd
  echo "===== 登录记录 ====="; last -n 30; lastb -n 20
  echo "===== 进程 ====="; ps aux --sort=-%cpu | head -40
  echo "===== 网络 ====="; ss -antp 2>/dev/null || netstat -antp
  echo "===== 计划任务 ====="; crontab -l; cat /etc/crontab; ls -alR /etc/cron* /var/spool/cron 2>/dev/null
  echo "===== 启动项 ====="; cat /etc/rc.local 2>/dev/null; ls -al /etc/init.d/ 2>/dev/null
  echo "===== 后门迹象 ====="; cat /etc/ld.so.preload 2>/dev/null; lsmod
  echo "===== SUID 文件 ====="; find / -perm -4000 -type f 2>/dev/null
  echo "===== 近 3 天修改文件 ====="; find /var/www /tmp /home /root /etc -type f -mtime -3 -ls 2>/dev/null | head -200
  echo "===== SSH 密钥 ====="; ls -al /root/.ssh 2>/dev/null; cat /root/.ssh/authorized_keys 2>/dev/null
} > "$OUT/report.txt" 2>&1
cp -r /var/log "$OUT/" 2>/dev/null
echo "采集完成：$OUT"
```

### 2. Windows（PowerShell，管理员运行）

```powershell
# 用途：应急响应场景快速采集基础信息（仅在授权环境使用）
$OUT = "C:\ir_$(Get-Date -Format yyyyMMdd_HHmmss)"; New-Item -ItemType Directory -Force $OUT | Out-Null
$report = "$OUT\report.txt"
"===== 时间 =====" | Out-File $report -Encoding utf8
Get-Date | Out-File $report -Append -Encoding utf8
(Get-CimInstance Win32_OperatingSystem).LastBootUpTime | Out-File $report -Append -Encoding utf8
"===== 账号 =====" | Out-File $report -Append -Encoding utf8
Get-LocalUser | Out-File $report -Append -Encoding utf8
Get-LocalGroupMember -Group Administrators | Out-File $report -Append -Encoding utf8
"===== 进程 =====" | Out-File $report -Append -Encoding utf8
Get-Process | Sort-Object CPU -Descending | Select-Object -First 40 Name,Id,Path,StartTime | Out-File $report -Append -Encoding utf8
"===== 监听端口 =====" | Out-File $report -Append -Encoding utf8
Get-NetTCPConnection -State Listen | Select-Object LocalAddress,LocalPort,OwningProcess | Out-File $report -Append -Encoding utf8
"===== 非系统路径服务 =====" | Out-File $report -Append -Encoding utf8
Get-CimInstance Win32_Service | Where-Object { $_.PathName -notlike "*\Windows\*" } | Select-Object Name,State,PathName | Out-File $report -Append -Encoding utf8
"===== 计划任务 =====" | Out-File $report -Append -Encoding utf8
Get-ScheduledTask | Where-Object { $_.State -ne "Disabled" } | Select-Object TaskName,TaskPath | Out-File $report -Append -Encoding utf8
"===== 启动项 =====" | Out-File $report -Append -Encoding utf8
Get-CimInstance Win32_StartupCommand | Out-File $report -Append -Encoding utf8
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" | Out-File $report -Append -Encoding utf8
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" | Out-File $report -Append -Encoding utf8
"===== 近 7 天修改的可疑文件 =====" | Out-File $report -Append -Encoding utf8
Get-ChildItem C:\ -Recurse -Include *.php,*.aspx,*.jsp,*.exe,*.ps1,*.bat -ErrorAction SilentlyContinue |
  Where-Object { $_.LastWriteTime -gt (Get-Date).AddDays(-7) } |
  Select-Object FullName,LastWriteTime,Length | Out-File $report -Append -Encoding utf8
"===== 安全日志关键事件 =====" | Out-File $report -Append -Encoding utf8
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4624,4625,4688,4720,4726,4697,4698,7045} -MaxEvents 300 -ErrorAction SilentlyContinue |
  Select-Object TimeCreated,Id,Message | Out-File "$OUT\security.log" -Encoding utf8
Write-Host "采集完成：$OUT"
```
